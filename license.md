## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Join breaks anonymity** | Remove PII keys |
| **Small groups exposed** | Increase k-threshold |
| **Charts cluttered** | Simplify palette |
| **Slow queries** | Add indexes |
| **Judges confused** | One clear takeaway |
| **Data versioning lost** | Add metadata header |
